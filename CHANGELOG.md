# Changelog

All notable changes to BreakerLedger are documented here.

## [0.1.0] - 2026-08-30

### Added

- Strict three-file CSV project validation with bounded input sizes and references.
- Evidence compilation into conflict, confirmed, tentative, and unmapped states.
- Deterministic mapping, directory, retest, JSON, and printable HTML reports.
- Clean, conflicting, and invalid CLI exit semantics suitable for automation.
- Formula-shielded CSV output and escaped, script-free HTML output.
- Healthy and intentionally conflicting example projects.
- Windows/Linux CI, source/wheel packaging, and clean-environment verification.
